# Esports Tournament Scheduler
 > A tournament scheudling and mangment program designed for Esports tournaments.

# About the Project 
> Esports Tournament Scheduler helps organize and run competitive tournament brackets from the command line.
> The scheudler currently supports team setup, player management, bracket generation, match resolution

# Features
* Bracket Management: Generates single-elimination brackets
* Team Management: Create, view, remove teams
* Matching Scoring: Record Match results and advance winners
* Visual Bracket Output: Prints readable ASCII bracket in the terminal

# Tech Stack
* Java 21
* Gradle

# Getting Started 
* Clone repo 
* In the root of the project run: 
* .\gradlew.bat :app  
* java -cp app/build/classes/java/main com.esportstournamentscheduler.CLI.App
